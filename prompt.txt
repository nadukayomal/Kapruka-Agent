4. DEVELOPMENT ORDER (Follow strictly)
==================================================

Phase 1: Project Setup
- Create full folder structure
- Create .env.example, requirements.txt, .gitignore, README.md
- Implement utils: config.py, logger.py, token.py, helpers.py

Phase 2: Playwright Crawler (Part 1)
- Build robust headless crawler for kapruka.com
- Extract: Product Name, Price, Description, Availability, Category, URL
- Handle pagination and dynamic loading
- Output clean catalog.json

Phase 3: Cognitive Memory (Part 2)
- Short-Term Memory (session buffer)
- Long-Term Memory (Qdrant + RAG on catalog.json)
- Semantic Memory (Recipient Profiles as JSON)

Phase 4: Specialist Orchestration (Part 3)
- Intent Router
- Catalog Specialist (RAG search)
- Logistics Specialist (Sri Lankan district delivery check)

Phase 5: Reflection Loop (Part 4)
- Draft → Critique (against allergies/preferences) → Revise
- Must block unsafe recommendations

Phase 6: Core Agent
- Custom Python control loop that connects everything
- No external agent frameworks

Phase 7: Backend API
- FastAPI endpoints so Next.js can communicate with the agent

Phase 8: Next.js Frontend (Bonus)
- Clean modern UI
- Chat interface
- “Thinking” panel (show Reflection steps)
- “Memory Recall” panel (show Semantic Memory)

Phase 9: Evaluation & Metrics
- Crawl success rate
- Preference Alignment rate
- Latency tracking
